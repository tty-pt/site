2. **State of `docs/AUDIT.md`**:
   - The old audit file had dozens of items that were already fixed (e.g. `mpfd` length bounding `F5`/`F7`, `E16` `per_page` clamp in `source-http.c`, `A2`–`A4`, `A6`, `A7`, `A9`, `A21`, `B1`, `B3`, `B4`, `C1`, `C3`, `C5`, `C6`, `D1`, `D2`, `D4`, `D7`, `D8`, `D9`, `D10`, `D14`, `D21`, `E1`, `E2`, `E4`, `E8`, `E17`, `F1`, `F2`, `F8`, `F9`, `F11`, `F13`, `F17`, no-site-specific-js).
   - The remaining real open issues need to be categorized by domain and prioritized by impact:
     - **Priority 1: Site-Level Security & Auth Hardening**:
       - `AUTH_SKIP_CONFIRM=1` forced unconditionally in `start.sh` (should only be active when `AUTH_ENV=dev` or explicit).
       - Auth routes (login/register/logout): CSRF protection on login/register; logout via POST.
       - User password validation: min length 8–12, buffer bounds, avoid truncation.
       - `GET /api/song/prefs` performs writes without CSRF (WASM client should use POST + CSRF).
     - **Priority 2: Storage & File Operations Hardening**:
       - `write_file_path` lacks `O_NOFOLLOW` / atomic swap or fsync.
       - `item_remove_path_recursive` needs prefix safety check ensuring it is strictly under `var/`.
     - **Priority 3: Submodule Architectural Debt (`axil`, `libxylem`, `hyle`, `bud`, `libqmap`)**:
       - `axil`: Request line buffer bounding, prevent unconstrained `input` heap growth on huge GET requests.
       - `libxylem`: Alloc error handling checks (`xy_deny`, `_xy_claim_for_load`), remove `/tmp/xy_bind.log` writes in default builds.
       - `hyle` / `stoma`: Incremental token indexing on mutations (currently full rebuild on dirty index), handle `qmap_field_put` failures.
       - `bud`: Tag/attribute name sanitization against injection in dynamic setters.
     - **Priority 4: Build & Code Hygiene**:
       - Dead `mods/site_core/` module directory: not in `mods.load` and not in `Makefile` build list (archive/remove or document).
       - CSS versioning `?v=` define manual bump vs build-time hash.
